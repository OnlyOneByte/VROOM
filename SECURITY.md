# Security Policy

## Supported versions

VROOM is under active development. Security fixes land on `main` and ship in the next
`main`/`dev` image; older releases don't get backports.

## Reporting a vulnerability

Please report security problems privately, not in a public issue or pull request.

- Use GitHub's private reporting: the repository's **Security** tab → **Report a
  vulnerability**.
- If that option isn't available, open an issue that asks for a private contact and leave out
  any details of the problem.

Include what you found, how to reproduce it, and what it lets someone do. You'll get a reply
once the report has been looked at, and credit in the fix if you'd like it.
